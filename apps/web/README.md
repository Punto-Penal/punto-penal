# @punto-penal/web

La aplicación Next.js con todas las pantallas de Punto Penal. Se generó con `create-next-app` 16.4 (App Router, TypeScript, Tailwind, ESLint, Cache Components).

Los comandos se corren desde la raíz del repo (`pnpm dev`, `pnpm lint`, `pnpm typecheck`); ver el [README principal](../../README.md). Las rutas van en español y el código en inglés; la forma de cada sección está en [estructura-del-repo.md](../../docs/arquitectura/estructura-del-repo.md) y en la skill `nueva-feature`.

`AGENTS.md` lo escribe `next dev`: apunta a la documentación de Next.js que viene en `node_modules/next/dist/docs/`, que corresponde a la versión instalada.
