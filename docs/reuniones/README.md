# Reuniones

Cada reunión deja un acta corta acá: qué se decidió, quién hace qué y qué quedó abierto. Lo que no está en un acta no se acordó.

- Nombre del archivo: `AAAA-MM-DD-tema.md` (por ejemplo `2026-11-20-arranque.md`).
- Partir de [plantilla.md](plantilla.md).
- Si se tomó una decisión importante, además del acta va su ADR en [../decisiones/](../decisiones/README.md).
- Lo que quedó abierto va a [../pendientes.md](../pendientes.md).

## Actas

Todavía no hay. La primera reunión cierra los pendientes de arranque.
